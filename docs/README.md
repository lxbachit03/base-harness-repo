# Team Documentation (`docs/`)

Thư mục này chứa các tài liệu nghiên cứu, đúc kết kinh nghiệm và tài liệu hướng dẫn dành cho người dùng và nhóm phát triển (Team-Facing Documentation).

> [!NOTE]
> Các tài liệu trong thư mục này **không** phải là ngữ cảnh nạp tự động của AI Agent hay Harness repo, trừ khi người dùng có yêu cầu cụ thể.

---

## Danh Sách Tài Liệu

- [**`AI_PROBLEMS.md`**](AI_PROBLEMS.md): Tổng hợp toàn diện 9 vấn đề / rào cản phổ biến nhất mà AI Agent thường gặp phải khi làm việc cùng User (Context Bloat, Trôi dạt mục tiêu, Sửa code ngoài phạm vi, Tuyên bố xong sớm, Mất trí nhớ giữa các session...) kèm theo phân tích nguyên nhân gốc rễ và bảng giải pháp kiến trúc khắc phục.
- [**`WORKFLOWS.md`**](WORKFLOWS.md): Phân tích chi tiết 5 trường phái kiến trúc & quy trình làm việc phổ biến của AI Agents hiện đại (Prompt Engineering, Loop Engineering, Graph Engineering, Context / RAG Engineering, Harness Engineering), chỉ ra ưu nhược điểm, cạm bẫy thực tế và ma trận ra quyết định lựa chọn kiến trúc.
