# Active Tickets

Use ../README.md for ticket identity, proportional artifacts, and lifecycle.
A single ticket lives at <ticket-number>-<slug>/ticket.md; batch tickets live
at <batch-slug>/<ticket-number>-<slug>/ticket.md.

Discover ticket.md recursively to identify active work; read only task-relevant
records. Keep resolved tickets here while User review or closure authority is
pending. Preserve existing inventories and manifests; new ones are conditional
on the ticket's evidence needs.
