# Proposals

This folder contains options, recommendations, and candidate solutions that
await or record User authority. A proposal is a suggestion, not an accepted
decision and not proof that a mitigation has been applied.

## Read When

Read this folder when the task evaluates alternatives, responds to a detected
risk, or needs a documented recommendation before a decision is made.

## Create And Maintain

- Use `docs-harness/templates/proposal.md`.
- State the problem, options, recommendation, consequences, residual risk, and
  rollback or recovery considerations.
- A proposal paired with a risk follows
  [#001_CONSTRAINTS_0812](../harness-constraints/0812-risk-proposal-suggestion-cross-link.md).
- Index each real proposal; do not treat the empty-state README as a proposal.

## Skip When

Skip this folder when no alternative, recommendation, or User decision is
relevant. Keep task-local choices in the active execution plan unless they have
lasting value.
