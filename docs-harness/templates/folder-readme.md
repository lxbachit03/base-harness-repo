# Folder README Template

Use this template for `README.md` in a `docs-harness/` folder whose rules,
ticket record or artifact manifest live in another file; raw requirement
init-harness-repo Yêu cầu 1.6 asks for a README in every folder. Keep it to a
few lines and point to the owner rather than repeating its rules or lists.

```markdown
# <Folder name>

<One or two sentences: what the folder holds and when to open it.>

<Owner link, for example: [layers/README.md](../README.md) owns the loading
rules.>

<Optional: one line per file or subfolder whose name does not explain it.>
```
